# Clip-Boy storefront — UX review (consolidated)

**Date:** 2026-08-21 · Two independent expert passes: (A) e-commerce/conversion + IA, (B) accessibility (WCAG 2.1 AA) + usability heuristics. Covers the live public page and the token-gated Run-2 preorder preview (`?preview=majesticm00se`).

**Headline:** the new preorder preview module is well-built (keyboard-accessible accordion, injection-safe rendering, good preorder expectation-setting). **Most of the serious accessibility defects live in the OLDER public page**, and the biggest conversion gaps are preorder trust/price-visibility. Nothing here is committed as a change — this is the menu.

---

## Bucket 1 — Preorder page: conversion & trust (highest ROI; in the gated preview)
1. **Refund/preorder terms buried + incomplete.** Only one dim cart-note ("Full refund before pre-orders close"). Spec §6 wants "before production starts" + an explicit **post-production stance** (no cancellation once building) — the page is silent on the hard part. FIX: visible "Preorder terms" block under the buy button; add a support email.
2. **Price hidden until a color row is expanded.** No price in hero or on collapsed rows. FIX: "From $X" near the hero; per-color price on each collapsed row.
3. **Best proof is gone in preorder mode.** "218% funded / 152 shipped in Run 1" lives in the hidden interest panel; About card renders below the whole buy flow. FIX: a one-line credibility strip near the hero.
4. **"Reserve yours" undersells a full charge today.** FIX: "pre-order yours" + "charged in full today" near the total; add "Secure checkout via Stripe."
5. **No at-cap feedback.** The stepper silently clamps at 5 (reads like a bug). FIX: show "5 max per order — contact us for bulk" when hit.

## Bucket 2 — Site-wide a11y: quick CSS wins (affects the LIVE page; low-risk)
6. **No `prefers-reduced-motion`.** `attention-pulse`, `uranium-sweep`, `.blink`, `.loading` all run infinitely. (~≤1 Hz, so no seizure risk — WCAG 2.2.2, not 2.3.1.) FIX: one `@media (prefers-reduced-motion: reduce){ animation:none }` block + `scroll-behavior:auto`.
7. **Contrast fixes.** Base palette passes (green 15.5:1, amber 12:1, even dim-green 5.95:1). Failures come from **`opacity`** on fine print (`.interest-fine` 0.7 ≈ 3.3:1; flavor span 0.8 ≈ 4.0:1) → raise to 1.0. And **`--pip-border` #143314 ≈ 1.5:1** used as the visible edge of interactive controls (delivery/donate buttons, inputs, `.po-color` rows) → use `--pip-dim` for interactive borders. Disabled buy-btn instructions at `opacity:0.4` (~2.9:1) are load-bearing status text → readable disabled treatment.

## Bucket 3 — Public-page a11y refactor (affects LIVE public code; bigger, higher value)
8. **Core controls aren't keyboard-operable.** Product cards, panels, and gallery images are `<div>`/`<img>` with `onclick` — no keyboard/SR access (WCAG 2.1.1/4.1.2). FIX: make them `<button>` or add `role/tabindex/keydown` — **the preview already does this right; backport the pattern.**
9. **Silent status/error messages.** `#msg` (checkout errors) and `#intlMsg` lack `aria-live` — copy the interest form's `role="status" aria-live="polite"`. Also `#poKsMsg` in the preview.
10. **Accordion/stepper semantics on the public page.** No `aria-expanded`; qty buttons lack `aria-label`; value changes not announced. (Preview does these correctly.)
11. **Modals.** Lightbox + intl modal need focus trap / initial focus / restore-on-close; intl modal has **no Escape**; intl close `×` < 44px; lightbox YT iframe lacks `title`.
12. **`#donateCustom` has no label** (placeholder only).

## Bucket 4 — Launch / backend (cannot be done in the frontend preview)
- **Real per-color images** — reclassified as a **launch blocker** (color-choice product; identical placeholders give nothing to choose on and undercut the +$10).
- Real **"PRE-ORDER" buy-button label** + the **§2a acceptable-use consent tick** in the real preorder checkout (the public store requires it; the preorder flow must too — consistency + AUP).
- **Donation param clamp** in `create_checkout` — both reviews re-flagged spec §0: `&donation=` is client-supplied; if unclamped a negative could underpay a live badge order **today**. Verify against the editor.
- Remove "(placeholder date)"; set real deadline/price/ship-estimate.
