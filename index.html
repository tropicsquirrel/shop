▶ AI & Tooling Transparency
Bryce designed the PCB and enclosure, defined the feature set, and made every call about what ships and what gets cut. He tested on physical hardware (some of it gloriously flaky).

Tools used along the way:

→ Claude + Claude Code — code review, PCB review, debugging partner
→ ESP32 Marauder by justcallmekoko — base for the Wi-Fi/BLE security tooling, ported to Clip-Boy with significant AI-assisted refactoring
→ Flux.1 Schnell & Gemini — collectible artwork (prompts written and curated by Bryce)
→ Adobe Firefly — image refinement and cleanup
→ ChatGPT — a handful of static graphics, including Clippy

Standard disclaimer: AI was used as a tool, like Git or a multimeter. The decisions, the design, the bugs, and the jokes are all Bryce's.
